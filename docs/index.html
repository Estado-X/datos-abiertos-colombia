Llévatelo a Excel o a tu IA

Llévatelo a Excel

El botón descarga un archivo que abre directo en Excel, con tildes y coma decimal. Trae hasta 5.000 filas: para todas, usa la descarga completa del portal o el conector.

Las celdas que empiezan con =, +, - o @ se guardan como texto, para que ninguna se ejecute como fórmula al abrir el archivo.

Llévalo a cualquier IA

«Llévalo a tu IA» copia un texto con el nombre del conjunto, quién lo publica, la fecha, sus columnas y la dirección para consultarlo. Pégalo en Claude, ChatGPT, Gemini o la que uses y escribe tu pregunta al final.

Pide siempre que la respuesta cite la entidad, el ID del conjunto y la fecha de actualización.

Conector para Claude, sin terminal

Con el conector, Claude busca, lee y cuenta los datos de datos.gov.co por su cuenta. Corre en tu computador y solo lee.

  1. 1

    Descarga el conector

    Descargar para Claude Desktop

    Archivo .mcpb. Necesitas Claude Desktop actualizado, en Windows o Mac.

  2. 2

    Ábrelo con Claude Desktop

    Haz doble clic en el archivo, o arrástralo a la ventana de Claude Desktop, y pulsa Instalar. La primera vez tarda uno o dos minutos mientras Claude Desktop prepara lo que necesita.

    Si el doble clic no lo abre: Configuración → Extensiones → Configuración avanzada → Instalar extensión…

  3. 3

    Pregúntale

    Por ejemplo: «¿Cuántos contratos del SECOP II firmó la alcaldía de mi municipio este año y por cuánto?». Claude te pide permiso antes de usar cada herramienta.

¿Usas Claude Code u otra IA? Instálalo con un comando

Necesitas uv instalado.

Claude Code:

claude mcp add datos-colombia -- uvx --from git+https://github.com/Estado-X/datos-abiertos-colombia datos-abiertos-colombia

Claude Desktop, LM Studio y otras con archivo de configuración (mcpServers):

{
  "mcpServers": {
    "datos-colombia": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/Estado-X/datos-abiertos-colombia", "datos-abiertos-colombia"]
    }
  }
}

Cómo colaborar

Esto es abierto y gratis: úsalo, cópialo y mejóralo.

  • Propón una pregunta para tu municipio: un conjunto de datos.gov.co con columna de lugar y para qué le sirve a la gente.
  • Cuéntanos si algo no funciona, con el municipio o el conjunto que probaste.
  • ¿Probaste el conector en otra IA? Cuéntanos cómo te fue.
  • Cópialo a tu cuenta y adáptalo a tu ciudad o a otro portal de datos.

Todo se hace en GitHub, gratis. La guía para colaborar está en CONTRIBUTING.md.

Límites

  • Los datos son de cada entidad que los publica y no están validados aquí: revisa fechas, unidades y valores atípicos antes de sacar conclusiones.
  • Todo se carga directamente desde datos.gov.co en tu navegador. Si el portal está lento o caído, esta página también.
  • Las preguntas del municipio dependen de los nombres de columna que use cada conjunto. Si datos.gov.co los cambia, la pregunta se pone en pausa con un aviso hasta que la ajustemos.
  • Muestra solo conjuntos de tipo tabla; los mapas, gráficos y enlaces externos del portal no aparecen.
