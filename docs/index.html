Llévalo a cualquier IA

El botón «Llévalo a tu IA» copia un texto con el nombre del conjunto, quién lo publica, la fecha, sus columnas y la dirección para consultarlo. Pégalo en Claude, ChatGPT, Gemini o la que uses, y escribe tu pregunta al final.

Pide siempre que la respuesta cite la entidad, el ID del conjunto y la fecha de actualización.

Conector para Claude

Con el conector, Claude busca, lee y resume los datos por su cuenta. Necesitas uv instalado.

Claude Code:

claude mcp add datos-colombia -- uvx --from git+https://github.com/Estado-X/datos-abiertos-colombia datos-abiertos-colombia

Claude Desktop (archivo claude_desktop_config.json):

{
  "mcpServers": {
    "datos-colombia": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/Estado-X/datos-abiertos-colombia", "datos-abiertos-colombia"]
    }
  }
}

Más detalles y otras formas de instalarlo en el README del repositorio.

Límites

  • Los datos son de cada entidad que los publica y no están validados aquí: revisa fechas, unidades y valores atípicos antes de sacar conclusiones.
  • El buscador y la muestra se cargan directamente desde datos.gov.co en tu navegador. Si el portal está lento o caído, este buscador también.
  • Muestra solo conjuntos de tipo tabla; los mapas, gráficos y enlaces externos del portal no aparecen.

Datos: datos.gov.co, portal de datos abiertos del Estado colombiano (MinTIC), con la licencia que indica cada entidad.
